# Obsolete built-in transcoder notes

The files in this directory document MuMuDVB's **removed** built-in transcoder
(`transcode_*` options) and historical FFserver usage.

Do **not** use these options with current MuMuDVB builds: they are no longer
parsed.

For current external transcoding, see:

* [`../TRANSCODE_EXTERNAL.asciidoc`](../TRANSCODE_EXTERNAL.asciidoc)
* MuMuDVB built-in HLS file mode (`hls=1`) in [`../README_CONF.asciidoc`](../README_CONF.asciidoc)
